Privacy

Effective 26 September 2026

SneakToken is a static site. There is no login, no database of users, and nothing you type into a calculator leaves your browser.

What we do not collect

No analytics, no cookie banner, no session recording, no advertising pixels. There is no account to create and no email field on this site — the calculators run entirely in your browser and are not transmitted anywhere.

Server logs

Our hosting provider necessarily sees standard request metadata such as IP address, user agent and the URL requested, in order to serve the files. We do not build profiles from it and we do not sell it.

Email

If you email us about a correction, we keep the message in order to answer it. That is the only personal data we hold, and it is only what you sent.

Outbound links

Some links to GPU rental and tooling providers are affiliate links. Clicking one tells that provider you came from us; it does not tell us anything about you. See the affiliate disclosure.

Changes

If this changes in a way that affects you, the date at the top changes with it.
