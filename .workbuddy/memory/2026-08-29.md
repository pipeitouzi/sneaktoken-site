## sneaktoken.com 海外英文站（从零搭建）

用户在腾讯云买了域名，要做面向海外客户的英文站，内容参考国内站 mianfeisuanli.com（免费大模型 API 额度库）。从零做出完整站点。

### 两个关键更正

1. **域名是 sneaktoken.com，不是 steaktoken**（用户首次口误）。sneak = 绕过付费墙，与"免费额度"主题天然契合 → 品牌叙事定为 "Sneak past the paywall"，比原本的 steaktoken 强很多。
2. **部署平台从 CloudBase 改为 Cloudflare Pages / Vercel**。我最初推荐 CloudBase 是错的：腾讯云上海环境绑定自定义域名走国内加速节点，会强制校验 ICP 备案，用户没备案会被卡死；且海外回源上海慢。已写入 DEPLOY.md。

**用户明确：sneaktoken.com 与 mianfeisuanli.com 完全独立，两套服务器，互不相干。**

### 站点产出

- `site/` 纯静态，无构建步骤。数据驱动：`data/offers.js` + `data/content.js`
- 结构：Hero + 筛选器（类型/条款/地区）+ 卡片网格 + 对比表 + How to pick + 方法论 + FAQ + 订阅 CTA
- 工具链：`tools/merge-offers.js` 把 `data/offers-*.json` 合并成 `site/data/offers.js`
- `DEPLOY.md`：CF Pages / Vercel 上线步骤 + DNSPod 解析表 + 检查清单

### 数据核实（本次最耗时、也最有价值的部分）

**结论：10 条，全部经官方页面确认，每条附源 URL。**

踩到的坑——搜索摘要和二手来源在这个话题上完全不可信：
- **Cerebras**：网上三个来源都说"无卡、每天 100 万 token"。抓官方文档发现 2026 年已取消无卡免费档，改为 $5 试用金 + 必须绑卡 + 30 天过期。
- **GitHub Models**：已于 2026-07-30 完全下线（官方原文 "fully retired"）。
- **Kaggle 网传"每周 30 小时免费 GPU"是误读**，那个数字属于付费 Colab 计划，免费档根本没公布周配额。
- **Lightning AI "每月 15 GPU 小时"** 官方已不再公布。
- **Together / RunPod / Vast.ai / Lambda / Baseten** 已无免费档。

第一个调研 agent 交付的 23 条数据**全部没有 source URL**，判定为搜索摘要拼凑，已隔离到 `data/unverified/`，不采用。

### 部署平台最终定为腾讯云 EdgeOne Pages（同日后续）

- 用户说"用腾讯云的海外站点部署" → 对应产品是 **腾讯云 EdgeOne Pages**（对标 Cloudflare Pages）。加速区域选"全球可用区（不含中国大陆）"即可免备案，DNS 在 DNSPod 不用挪，自动签免费 SSL。比 Cloudflare Pages 更顺（控制台在国、DNS 不切）。
- 已重写 `DEPLOY.md` 为 EdgeOne Pages 路径，并打了部署包 `sneaktoken-site.zip`（用 Python zipfile 打包，排除 `_headers`/`vercel.json`，因为 CF/Vercel 专属文件在 EdgeOne 用不上）。
- 注：没有现成的 EdgeOne Pages MCP 工具可直接部署，需用户在腾讯云控制台手动上传 zip 或连 Git 仓库。
